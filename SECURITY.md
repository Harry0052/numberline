# Security policy

NumberLine is a local linter. It reads the Markdown file and claim file you pass on the command line and writes only the report path you set with `--output`.

## Reporting a vulnerability

Open a private security advisory on this GitHub repository:

https://github.com/Harry0052/numberline/security/advisories/new

Please include the version, the fixture or input shape that triggers the issue, and whether it affects classification, file handling, or the report renderer. Do not include real patient data, credentials, or unpublished manuscripts.

There is no hosted service and no account system. A report about the local tool is enough.

## Supported version

Security fixes apply to the current 0.1.x line published from this repository.
